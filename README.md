# Hitomi Tweak

> ⚠️ **Disclosure / Pernyataan:** This script was made 100% using AI. / Script ini dibuat menggunakan AI 100%.

Userscript for [hitomi.la](https://hitomi.la): poster grid, dark mode, vertical webtoon-style reader, tag filter, hover preview, romaji titles, and a background download manager (ZIP / PDF / images).

Userscript untuk hitomi.la: poster grid, mode gelap, reader scroll vertikal ala webtoon, filter tag, hover preview, judul romaji, dan unduhan di latar belakang.

## Install

1. Install a userscript manager, e.g. [Tampermonkey](https://www.tampermonkey.net/) or Violentmonkey.
2. Open **[hitomi-tweaks.user.js](https://raw.githubusercontent.com/qxyraxp/hitomi-tweaks/main/hitomi-tweaks.user.js)** and click **Install**.

The script updates itself when a new version is pushed to this repo.

## Usage

- Open settings: the **⚙ Settings** item in the navbar, or `Alt+S`.
- Tag filter: **🏷 Filter** in the navbar, or `Alt+T`.
- Language (Indonesia / English): Settings → Appearance → Language.
